[qdvc-cursed-knowledge's WRITING-REPORTS.md](https://github.com/qdvc-apps/qdvc-cursed-knowledge/blob/main/docs/WRITING-REPORTS.md)
using its [template](https://github.com/qdvc-apps/qdvc-cursed-knowledge/blob/main/reports/TEMPLATE.md).

Each file here is named `YYYY-MM-DD-<platform>-<short-slug>.md`, one gotcha per
file, and is meant to be copied into `reports/inbox/` of the cursed-knowledge
repository.
